# 初始工程与学员任务的边界

## Leader 已准备

- 空工程、固定依赖、启动入口、Maven Wrapper、pnpm lockfile。
- PostgreSQL／Redis 连接参数及本机 Compose。
- 前后端最小启动测试、独立的基础设施连接检查。
- 最小格式与静态检查配置、启动说明。

## 学员实现

| 类别 | 实现内容 | 依据 |
| --- | --- | --- |
| 前端共通 | 初始化、Route、Layout、菜单、通信、Session、Message、Form、Loading | 对应共通详细设计 |
| 后端共通 | 响应、异常、参数校验、日志、认证、Permission、Data Scope | 对应共通详细设计及基本设计正本 |
| 画面 | 固有项目、Event、输入、API 调用、错误显示 | 各画面详细设计 |
| API | 请求处理、业务规则、SQL、事务、排他 | 各 API 详细设计 |
| DB | DDL、Migration、索引、约束、初始数据 | 各 DB 详细设计；不增加物理外键 |
| Batch | 起动、业务处理、排他、例外、恢复 | 各 Batch 详细设计 |
| 测试 | 正常／异常／边界、具体输入与期待结果、证迹 | 对应详设及单体测试式样书 |

依赖库不等于共通功能完成。健康检查不等于业务 API。启动用 App.tsx 不等于正式 Layout 或 SCR-001。

当前工程不提前绑定某种业务分层、Method 名或项目 Route，不替代已确认模板和详细设计。
