# 開発環境構築

1. Gitを導入する。
2. JDK 17を導入し、`java -version` で17を確認する。
3. EclipseにJDK 17を登録する。
4. Node.js 22.13.xとnpm 10.xを導入する。
5. PostgreSQL 16を導入し、`company_workhub` DBを作成する。
6. Docker Desktopを導入し、Redisだけを起動する。
7. RepositoryをCloneし、BackendとFrontendの初回Buildを行う。

| 対象 | Host | Port | Database/User |
| --- | --- | --- | --- |
| PostgreSQL | 127.0.0.1 | 5432 | company_workhub / workhub_app |
| Redis | 127.0.0.1 | 6379 | password: workhub_local |
| Backend | 127.0.0.1 | 8080 | - |
| Frontend | 127.0.0.1 | 5173 | - |

個人都合でPortや認証情報を変更せず、変更が必要な場合はLeaderへ連絡する。Integration接続情報は `config/application-integration.yml` にのみ設定し、GitへCommitしない。
