# 結合テスト接続手順

1. `config/application-integration-example.yml` を `config/application-integration.yml` としてCopyする。
2. Leaderから通知されたHost、Port、User、Passwordへ置換する。
3. `application-integration.yml` がGitの対象外であることを確認する。
4. OS Firewallおよび接続許可時間を確認する。
5. `integration` ProfileでAPIまたはBatchを起動する。
6. Health、DB参照、Redis PINGを確認してから結合テストを開始する。

共有DB/Redisは結合テスト専用であり、Local開発や単体テストから常用しない。他担当の試験データを削除しない。
