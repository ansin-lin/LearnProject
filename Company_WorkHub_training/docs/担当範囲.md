# 初期コード基盤と学員担当範囲

## 基盤で提供するもの

- Maven Multi Module と React/Vite のビルド構成
- Spring Boot API / Batch の起動クラス
- PostgreSQL / Redis の接続設定枠
- Spring Security の最小Bootstrap設定
- Frontendの基本画面とテスト起動確認
- CIによるBuild、静的解析、Test
- Local / Test / Integration Profileの切替方式

## 学員が詳細設計に基づき実装するもの

- 共通Response形式
- 共通例外処理とError/Message変換
- Bean Validationおよび業務Validation
- JWT発行、検証、更新、Logout
- Role、Permission、Data Scope判定
- Controller、Service、Mapper、SQL
- React Route Guard、API Client、State、各業務画面
- File、Log、監査、Redis利用処理
- Spring Batch Job、Redis排他
- 単体テストおよびEvidence

基盤に業務完成形を含めない。学員は基本設計・詳細設計を正本として実装し、実装上の判断で業務仕様を追加しない。
